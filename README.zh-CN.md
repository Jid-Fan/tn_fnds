# tn_fndScream

[English](README.md) | [简体中文](README.zh-CN.md)

主要面向极端嗓，以及具有强非周期性或不稳定发声结构的 UTAU 音源。

它不是面向普通清嗓或强音源的通用重采样器。即使某个强音源具有清晰的谐波结构，
使用实验性模式时也可能出现合成感、音高不稳定甚至报错。
特别是，`hs` 不适合当作“把极端嗓变成自然清嗓”的转换器；目前不建议为了获得
清嗓效果而使用 `hs100`。

## 快速开始

将 `tn_fndScream.exe` 安装为 OpenUtau / UTAU 的重采样器。

如果使用 OpenUtau 里的表达式控制，可以将 `tn_fndScream.zh.yaml` 重命名为
`tn_fndScream.yaml`，并将它放在与 `tn_fndScream.exe` 相同的文件夹。然后在
Project Expressions 中选择“获取渲染器建议的表情”。

建议先使用默认设置，也可以尝试：

```text
W-1
W-1，并将循环模式设为 `pingpong`
W-1hq1
W-1mf100hq2
W-1hs100
W-1mf100
W-1，并将循环模式设为 `pingpong`，再设置 `ls500` 和 `lf-300`
```

建议按以下顺序调试：

1. 先只使用 `W-1`。
2. 如果正向循环感太明显，将循环模式设为 `pingpong`。
3. 如果循环边界位置不合适，调整 `ls` 和 `lf`。
4. 如果边界出现点击声、爆音或短促杂音，调整 `cf`。
5. 需要改变音高时，对比 `mf`、`hq1` 和 `hq2`。
6. 想把稳定元音区变得更清晰、更有谐波时，尝试 `hs`。
7. 基本循环和音高效果确定后，再尝试 `sv` 或 `A`。

## Flag 说明

### 声音和音高

| Flag | 范围 | 说明 |
| --- | ---: | --- |
| `W` | `-1`、`0–50`、`51–1000` | 选择重采样器使用的音高来源。`W-1` 尽量不强行使用分析得到的旋律基频，通常适合作为混沌极端嗓的起点。`W0–50` 使用分析得到的音高。`W51–1000` 使用指定的固定基频。 |
| `mf` | `0–100` | 旧版颗粒间距变调模式。它改变残差颗粒之间的间距。较大的音高变化可能保留较有特点的高音，但也可能出现颗粒感、卡顿或不稳定。 |
| `hq1` | `0–1` | 启用一条基于 Rubber Band、带共振峰保持的完整波形连续变调路径。它在不同音源和变调幅度下可能更平滑，也可能更不合适，并且可能比另一条路径占用更多 CPU。 |
| `hq2` | `0–2` | 实验性的极端嗓混合路径：用 Rubber Band 变调低频音高骨架，同时保留原始高频嘶声、噪声、shimmer 和其他不稳定纹理。主要面向极端嗓，普通音源可能出现叠层感或跑调感。 |
| `t` | 约 `-100–100` | 音高偏移，每单位约为 10 音分。 |
| `A` | `0–100` | 补偿音高变化造成的响度变化。它不是普通的音量自动化替代品。 |
| `P` | `0–100` | 近似响度标准化。`P0` 保持原来的输出电平；数值越大，越会把有效片段的 RMS 推向较统一的目标。这不是 LUFS 测量。 |

### 音色处理

| Flag | 范围 | 说明 |
| --- | ---: | --- |
| `hs` | `0–100` | 将稳定元音区替换为谐波层，并用随时间变化的频谱包络跟随原音的大致口型/共振峰变化。它是极端嗓音色实验，不是自然清嗓转换器；高数值可能发糊、像合成器或金属声。默认 `hs0` 不改变声音。 |
| `he` | `0–100` | 在每个理论谐波附近寻找实际频谱峰并增强它，不添加新的谐波，也不替换原始波形。它允许极端嗓的实际音高有一定漂移，因此比精确频率增强更容易听见。 |
| `hf` | `0–100` | 实验性地强行建立旋律谐波层。当 `he` 找不到足够的原有能量时，`hf` 会在目标位置补少量随机相位的周期成分。它可以让没有谐波的声音产生旋律感，但也可能明显合成化。 |
| `ho` | `-2000–2000` 毫秒 | 手动移动自动估计的 `hs` 起点。正值让谐波清化更晚开始，负值让它更早开始。`ho0` 不改变自动估计结果。 |

### 循环

| Flag | 范围 | 说明 |
| --- | ---: | --- |
| 循环模式 | `forward` / `pingpong` | 选择正向循环或连续波形正向/反向循环。默认是 `forward`。 |
| `ls` | 毫秒 | 偏移循环起点。正数使起点向后移动，负数使起点向前移动。 |
| `lf` | 毫秒 | 偏移循环终点。负数使终点提前。正数不能像“向后延长可用 oto 区域”那样无限生效。 |
| `cf` | `0–1000` 毫秒 | 循环边界交叉淡化。较长的交叉淡化可能让接缝更平滑，但也可能降低听感响度或模糊重要的音头。 |
| `rs` | 毫秒 | 在指定范围内随机偏移每次循环的起点。建议先使用较小的值。 |
| `rf` | 毫秒 | 在指定范围内随机偏移每次循环的终点。建议先使用较小的值。 |
| `sv` | `0–100` | 进行慢速响度稳定。它可以减轻短录音或不稳定录音中较大的整体响度变化，同时尝试保留较快的 shimmer。 |

### 频谱和辅音控制

| Flag | 范围 | 说明 |
| --- | ---: | --- |
| `O` | `-100–100` | 改变频谱开放度。正值通常使频谱更开放、更明亮，负值则相反。 |
| `b` | `0–100` | 增大清辅音的响度。 |
| `B` | `0–100` | 原重采样器继承的呼吸/噪声控制。在极端嗓上可能不太容易预测。 |
| `g` | `-100–100` | 原重采样器继承的性别/音色控制。 |
| `e` | 选项 | 改变原重采样器的伸缩行为。它不是为解决极端嗓循环问题设计的，可能反而使极端嗓不自然。 |

`g` 和原重采样器的其他标准控制仍然保留，以维持兼容性。`tn_fndScream`
的主要实验性控制是 `W`、`mf`、`hq`、`hs`、`he`、`hf`、循环模式、`ls`、`lf`、`cf`、`rs`、`rf`
和 `sv`。

`hs` 与 `hq` 是分开的：`hs` 是音色处理效果，不是变调算法选择器。

## 如何选择循环方式

### 正向循环

正向循环会让选定区域始终以同一个方向重复播放。当循环区间本身比较稳定、
前后响度也比较一致时，正向循环通常更干净。

### 正反循环（`pingpong`）

正反循环会先正向播放选定区域，再反向播放。对于较短的极端嗓录音，如果
循环区间的开头和结尾无法自然衔接，它有时会比正向循环更好。

但倒放并不一定更好。如果选定区域包含明显音头、突然的响度变化或快速变化
的声音事件，反向部分可能出现合成感或明显接缝。此时可以调整 `ls`、`lf`
或 `cf`，也可以改回正向循环。

旧版的“残差颗粒倒放”方法已经移除。现在的 `pingpong` 使用连续波形倒放。

## 按听感排查问题

### “循环处突然像跑调了”

尝试移动循环起点或终点：

```text
ls-200
lf-300
```

这种听起来像变调的现象，可能是循环边界切过了局部周期结构，并不一定是
重采样器主动改变了旋律音高。

### “循环边界有点击声、爆音或‘嗒’‘噗’声”

尝试较短的交叉淡化：

```text
cf50
cf100
```

如果交叉淡化变长后反而更小声或更模糊，就把它调小。交叉淡化不能修复
本身就不适合循环的区间。

### “倒放部分有持续的合成音”

尝试用 `ls` 和 `lf` 移动循环边界。尽量避开明显音头、突然衰减或变化很快
的声音区域。如果倒放部分仍然很假，可以改用正向循环。

### “声音变得很颗粒，或者像卡住了”

这是旧版 `mf` 路径的已知取舍。可以与以下模式对比：

```text
hq1
```

`mf`、`hq1` 和 `hq2` 是三条不同的合成路径，不能保证哪一条更适合极端嗓。`hq2`
更重视保留原始极端嗓的高频纹理。
实际结果取决于录音本身和需要的音高变化。

### “循环过程中的响度变化很大”

可以尝试：

```text
sv30
sv60
```

建议先从中等数值开始。极端嗓中的 shimmer 和非线性变化可能是真实的声音
特征，过度稳定响度会让声音失去活性。

### “我想把极端嗓变得更清晰、更像有谐波的声音”

可以尝试：

```text
hs30
hs60
hs100
```

这只是极端嗓音色实验，不建议把它当作“清嗓化”功能。当前版本在 `hs100` 下
可能失去原歌手的发音清晰度和音色；若目标是自然清嗓，建议使用专门面向清嗓的
音源和重采样器。

效果会从自动估计的辅音/不稳定音头边界之后开始。如果估计点太早或太晚，
可以用 `ho` 手动偏移。它使用稳定元音的平滑频谱包络作为大致的口型/共振峰
形状。数值越高，谐波替换越明显。由于频谱包络会随原音变化，而不是整段使用一个
固定的元音形状，因此能保留大致的口型运动；在 `hs100` 时不会继续带入原始的
shimmer 和噪声。但它仍可能带有合成感，因为添加的谐波结构并不是录音中原本存在
的结构。

## 已知限制

- `oto.ini` 和 `frq` 的质量会显著影响结果。
- `W-1` 并不等于真正没有音高，它主要是尽量避免在循环处理中强行使用分析
  得到的旋律基频。
- `W0–50` 更依赖音高分析数据，不一定适合混沌或气声很多的录音。
- `W51+` 的固定基频在不同音源上可能听起来更低、更亮，或产生其他预料之外
  的音色变化。
- 短录音能够用于稳定循环的区域很少，仍然可能需要手动调整循环边界。
- `hq1` 和 `hq2` 可能更慢，并且可能产生与旧颗粒路径不同的声音身份。
- `hq2` 是实验性算法，使用保守的频率分离，并不保证能准确区分谐波和噪声。
- `hs` 是实验性谐波化处理，不是训练好的神经声码器，也不是极端嗓到自然清嗓
  的转换器。它不知道准确的元音身份，高数值下可能发糊、失去原音色，或听起来
  像蜂鸣、合成器或金属声。
- 如果循环区间包含明显的音高、频谱或响度变化，`pingpong` 仍然可能听起来不自然。
- 这是一个实验性重采样器。对于普通清嗓音源，不保证效果优于成熟的通用
  重采样器。

## 从源代码编译

```text
cd src
mingw32-make -f Makefile -j1
```
